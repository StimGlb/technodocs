# TechnoDocs - Quick Context

## Stack
Vanilla JS ES6+ | Firebase v10+ (modulaire) | Vite | Netlify | Backend séparé en dev

## Règles strictes
- Jamais `innerHTML` → `createElement` ou `DOMParser`
- Firebase: syntaxe modulaire uniquement (`import { doc } from 'firebase/firestore'`)
- Pas de scripts inline → tout externalisé
- CSS Variables pour theming

## Niveau dev
Vibe-codeur : exemples concrets > théorie. Montre juste le bloc modifié, pas tout le fichier.

## Réponses format
1. Résumé 1 ligne
2. Code modifié avec commentaires
3. Action à faire (si besoin)

Style : direct, efficace, emojis structurants (🚀 ✅ ⚠️)
