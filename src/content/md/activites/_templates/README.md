# \_templates/

Fichiers de **référence** pour la rédaction de fiches d'activité Markdown.

## Contenu

| Fichier              | Usage                                                                  |
| -------------------- | ---------------------------------------------------------------------- |
| `GUIDE-STRUCTURE.md` | Guide complet : classes CSS, champs wizard, mode dual print/interactif |
| `squelette.md`       | Squelette minimal prêt à copier                                        |

## Workflow

1. Copier `squelette.md` → `../s{session}-{niveau}-{nom}.md`
2. Suivre le guide `GUIDE-STRUCTURE.md` pour les classes disponibles
3. Voir `docs/wizard/STRUCTURE.md` pour les conventions de nommage
