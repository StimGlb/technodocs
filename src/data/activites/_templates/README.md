# \_templates/

Schémas JSON de **référence** pour les données d'activités.

## Contenu

| Fichier                 | Usage                                             |
| ----------------------- | ------------------------------------------------- |
| `exemple-activite.json` | Structure type d'un fichier de données d'activité |

## Convention de nommage

```
{niveau}-activite-{nom}.json
```

Exemples : `3e-activite-consommation-maison.json`, `5e-activite-reparabilite.json`
